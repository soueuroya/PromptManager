# Task Guide

## Required Reading Order

Before modifying the project:

1. AGENTS.md
2. PROJECT_CONTEXT.md
3. ARCHITECTURE.md
4. ROADMAP.md

Then inspect the relevant implementation files.

## Core Development Rules

### Keep Layers Separated

Business logic:

```txt
PromptManagerState.ts
```

VS Code APIs:

```txt
PromptManagerViewProvider.ts
```

UI rendering:

```txt
PromptManagerHtmlRenderer.ts
```

Shared models:

```txt
models.ts
```

## Common Task Patterns

### Adding a New UI Feature

Usually requires updates in:

- PromptManagerHtmlRenderer.ts
- PromptManagerViewProvider.ts
- PromptManagerState.ts

Typical flow:

```txt
Button/UI
 |
 v
postMessage()
 |
 v
Provider handler
 |
 v
State method
 |
 v
save()
 |
 v
refresh()
```

### Adding New Data

Usually requires updates in:

- models.ts
- PromptManagerState.ts
- PromptManagerHtmlRenderer.ts

Also verify:

- Persistence compatibility
- Snapshot serialization
- Queue payload compatibility

### Updating Queue Behavior

Update:

- `buildTaskPayload()`
- `buildPromptPayload()`

Inside:

```txt
PromptManagerState.ts
```

Queue payloads should remain:

- Structured
- Explicit
- AI-readable
- Implementation-focused
- Validation-focused

### Updating Webview UI

Update:

```txt
PromptManagerHtmlRenderer.ts
```

Prefer:

- Compact layouts
- Inline editing
- Drag/drop
- Collapsible sections
- Lightweight interactions

Avoid:

- Modal-heavy flows
- Giant forms
- Excessive nesting

## Important Files

### package.json

Controls:

- Sidebar registration
- Activation
- Commands
- Extension metadata
- Packaging behavior

Be careful when modifying IDs.

### media/

Contains extension icons and assets.

Missing media files can break VSIX packaging.

### dist/

Compiled output generated by esbuild.

Should not be edited manually.

### esbuild.js

Controls extension bundling/build pipeline.

## Definition of Done

Before considering work complete, run:

```bash
npm run compile
vsce package
```

Then manually verify:

- Extension activates
- Sidebar appears
- Tasks work
- Prompts work
- Queue works
- Persistence survives reload
- Drag/drop still works
- VSIX installs correctly
- No missing assets
- No TypeScript errors
- No lint errors

## Persistence Safety

Never casually break saved workspace data.

If changing snapshot structure:

- Preserve compatibility
- Or add migration handling

## UX Priorities

PromptManager should feel like:

- An AI workflow dashboard
- A queue orchestration tool
- A lightweight node/workflow system

Not:

- A plain tree view
- A simple markdown editor
- A basic prompt list
